TTES-050-004. Generated by `tools/ttes-governance-dashboard.mjs`; run it with
`--check` to fail on a stale copy, and
`tests/architecture/ttes-governance-dashboard.test.mjs` does that in CI.

**Nothing here is written by hand.** Adoption is counted from the imports in
329 shipping modules under `apps/web/src`; the exception table is read
out of `DESIGN_TOKEN_EXCEPTIONS` in `apps/web/eslint.config.mjs`; every debt row
is attributed to the domain `tools/ownership-map.mjs` assigns the file, which is
the same answer the ownership ratchet gives.

This measures the **tenant** experience. `apps/system-studio` is a separate
experience with its own stylesheet and its own components (TTES-000-001), and
mixing the two would produce a number that describes neither.

## 3. Visual debt — contracts with a sanctioned alternative, not yet enforced

A row belongs here only if the alternative already exists. That is the line
between debt and an unmade decision, and it is why easing keywords are here and
arbitrary spacing is here while something with no owned replacement is not.

The budget equals the measurement on the day it was recorded. The guard fails in
both directions: over budget is a regression, under budget is a budget nobody
lowered.

| Class | Occurrences | Files | Budget | Sanctioned alternative |
|---|---|---|---|---|
| `arbitrary-spacing-type` — Tailwind arbitrary spacing and type values (`p-[7px]`, `text-[13px]`) | 275 | 66 | 275 | `--space-1…16` and `--step-00…4` in `globals.css`, bound in `tailwind.config.ts` |
| `raw-button-element` — A raw `<button>` in a product module | 106 | 55 | 106 | `Button` from `@/components/ui/Button` |
| `raw-text-input-element` — A raw text `<input>` or `<textarea>` | 72 | 32 | 72 | `TextField` from `@/components/ui/TextField` (`multiline` for the textarea) |
| `raw-select-element` — A raw `<select>` | 27 | 13 | 27 | `Select` from `@/components/ui/Select` |
| `hand-rolled-page-heading` — An `<h1>` written by a page instead of the owned page header | 29 | 28 | 29 | `PageHeader` from `@/components/ui/PageHeader` (identity → status → primary actions) |
| `easing-keyword` — A CSS easing keyword (`ease-out`, `ease-in`) in a product module | 9 | 5 | 9 | `ease-entry` / `ease-exit`, bound to `--ease-entry` / `--ease-exit` |

Why each is debt rather than a rule:

- `arbitrary-spacing-type` — Named as this requirement's own item by `apps/web/eslint.config.mjs`: a rule here is a cleanup project across the whole product rather than a boundary.
- `raw-button-element` — The owned Button carries the variant, the size, the focus ring and the pressed state. Two hand-rolled copies of its secondary class string had already drifted apart before TTES-020-003 removed them.
- `raw-text-input-element` — The owned field carries the label, the description, the error message and the invalid state. Checkbox, radio, file and hidden inputs are NOT counted: no owned wrapper exists for them, so they would be a ban rather than debt.
- `raw-select-element` — Same reason as the field: the owned wrapper is what keeps the popover, the keyboard model and the states consistent.
- `hand-rolled-page-heading` — The TTES authority `Tenure_Tenant_Experience_System_and_Product_UIUX_Claude_Bible_v1.0.md` §5.3, record anatomy. `TTES-030-001` is FAIL for exactly this reason and names the five club surfaces that still hand-roll a heading; this is the number that has to reach zero for it to close.
- `easing-keyword` — `apps/web/eslint.config.mjs` declines to ban these because `ease-out` is a keyword rather than a magic number and a rule would red files that change did not own. That makes it debt, tracked here.

## 6. What this dashboard does NOT establish

Written down because an unstated limit in a governance document reads as
coverage, which is the failure `docs/architecture/ttes-experience-audit.md` §7
exists to avoid.

- **Rendered adoption.** An import is not a render. A module can import `Button`
  and still hand-roll one beside it; §1 counts the import.
- **Whether a raw element is wrong.** Some of the 106
  raw buttons are inside owned patterns that predate the wrapper and some are
  genuinely one-off. The budget is a ratchet on the total, not a verdict on a
  line.
- **Design-quality debt.** Spacing rhythm, hierarchy, copy tone and iconography
  consistency are judgements. Nothing here measures them, and no number in this
  document should be read as measuring them.
- **The console.** `apps/system-studio` has its own stylesheet, its own
  components and its own debt. It is out of scope by §1 of the TTES authority.
- **Runtime adoption by tenants.** Which tenants render which surface is a
  deployment question; this reads the repository.
